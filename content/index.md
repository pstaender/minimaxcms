# A small, fast home for your words

Write Markdown, save it in `content/`, and it's a page. No database, no admin, no build step.

![MiniMax monster](./monster.svg)

<p class="actions"><a href="/blog/">Read the blog</a><a href="/about">About MiniMax CMS</a></p>

## Why MiniMax

- **Flat files** Every file in `content/` is a page, every folder a subpage.
- **Markdown first** GitHub flavoured Markdown with front matter, or plain PHP and HTML.
- **Lightweight** Plain PHP templates, curated selection of helpers and image optimization included.
